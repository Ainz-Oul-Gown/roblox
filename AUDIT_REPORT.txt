  Файлы: PetService.luau, RetentionService.luau, init.server.luau
  Проблема:
    - PetService.playerInventories — только в RAM
    - RetentionService.playerDataMap — только в RAM

  Патч:
    - Расширить PlayerSaveData в DataStoreManager: pets, streak, lastClaim
    - Передавать saved-данные в initPlayer при загрузке
    - Сохранять при onPlayerRemoving и автосохранении

P0-07: DataStoreManager — SetAsync вместо UpdateAsync, нет Session Lock
  Файл: DataStoreManager.luau, строка 133
  Проблема:
    - tycoonDataStore:SetAsync(key, validated) — слепая перезапись
    - Нет session locking (вопреки скилу roblox-data-persistence)
    - Телепорт/хоп между серверами = две сессии одновременно
    - Последний SetAsync затирает данные другого сервера
  Патч:
    - Использовать UpdateAsync с compare-and-set
    - Реализовать session lock через MemoryStoreService
    - Или метаданные lock в самом DataStore (sessionId + timestamp)

P0-08: BindToClose ждёт только 1 секунду — потеря данных
  Файл: init.server.luau, строки 401-405
  Проблема:
    - task.wait(1) — Roblox даёт до 30 секунд
    - saveAllPlayers() -> task.spawn для каждого игрока
    - Каждый save: до 3 ретраев * 1.5с задержки = до 4.5с
    - 8 игроков параллельно, но DataStore throttling может растянуть
    - 1 секунда ГАРАНТИРУЕТ незавершённые сохранения
  Патч:
    - Увеличить до task.wait(25)
    - Или собрать все task.spawn в coroutines и дождаться завершения
    - Пример: счётчик завершённых + while count < total do task.wait(0.1) end

P0-09: NaN/Infinity может попасть в data.cash
  Файлы: EconomyManager.luau, TycoonService.luau
  Проблема:
    - EconomyManager.addCash: math.floor(amount * mult)
    - Если amount = NaN или mult = NaN -> результат NaN
    - NaN записывается в data.cash -> все операции ломаются навсегда
    - NaN >= cost = false, NaN + X = NaN — вечный тупик
    - Сохраняется в DataStore -> поломка аккаунта навсегда
  Патч:
    - В addCash: if amount ~= amount or mult ~= mult then return currentBalance end
    - В validateAndMigrate: if cash ~= cash then cash = 0 end
