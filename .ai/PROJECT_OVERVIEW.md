# Project Overview: Gen Alpha Brainrot Multiplayer Tycoon

## Описание проекта
**Gen Alpha Brainrot Multiplayer Tycoon** — мультиплеерный тайкун на **8 игроков** в стилистике интернет-культуры поколения Альфа (Skibidi, Mewing, Sigma, Fanum Tax, Grimace, CaseOh, Rizzler, Tung Tung). Проект включает 8 круговых баз вокруг центральной боевой арены, интерактивное меню выбора базы/фракции (`FactionSelectModal`), физические стартовые площадки (`ClaimPad`), 8 уникальных суперспособностей со встроенным экранным таймером и тостами, лазерную защиту базы с герметичным периметром стен, 5 уровней Rebirth и современный экранный HUD.

## Ключевые системы и последние исправления
1. **Конвейер и сбор руды**:
   - Направление движения строго вперед по локальной оси $+Z$ в сторону Сборщика Ауры (`baseCF:VectorToWorldSpace(Vector3.new(0, 0, 1))`).
   - Настроены `CustomPhysicalProperties` на конвейере и руде (нулевая упругость, низкое трение руды), исключающие отскоки.
   - Металлический задний стоппер (`ConveyorBackstop`) и боковые бортики (`BorderLeft`, `BorderRight` высотой 2.5 стада) предотвращают вылет руды.
   - Увеличенный Сборщик Ауры (ширина 6 стадов) со счетчиком и защитой от дублирования (`Collected`).
2. **Герметичный периметр стен и защита**:
   - Передний фасад полностью запечатан: `WallFrontLeft` (от $X = -17$ до $-5.5$) и `WallFrontRight` (от $X = +5.5$ до $+17$) встык с боковыми стенами.
   - В проеме установлены лазерные ворота (`LaserGate`) с верхней балкой-перемычкой (`GateLintel` на высоте 9.5 стадов), исключающей перепрыгивание.
   - Защитный сенсор лазера корректно обрабатывает касания как телом, так и аксессуарами/шляпами, мгновенно ликвидируя нарушителей.
3. **Система способностей и отзывчивый HUD**:
   - Способность доступна сразу при выборе базы (базовый кулдаун 12 сек).
   - Покупка `FactionAbilityStand` сокращает время перезарядки в 2 раза (до 6 сек).
   - Кнопка на клиенте отображает живой обратный отсчет кулдауна (`⏳ 12с`, `⏳ 11с` ...), блокирует клики во время перезарядки и восстанавливает цвет по завершении.
   - Система всплывающих тостов информирует об активации способности, кулдауне и предупреждениях.

## Стек технологий
- **Платформа**: Roblox
- **Инструмент синхронизации**: Rojo v7.7.0 (бинарник в `bin/rojo.exe`, плагин в `%LocalAppData%\Roblox\Plugins\Rojo.rbxm`)
- **Язык**: Luau (strict typing `--!strict`)
- **Мультиплеер**: 8 независимых баз по круговой сетке ($R = 90$ studs), меню выбора фракции, центральная зона царя горы `(0, 0, 0)`
- **Сохранение**: Roblox DataStoreService (`TycoonSave_v1`)
- **Тестирование**: Node.js Test Runner (`npm test`, 27 юнит-тестов)
- **CI/CD**: GitHub Actions (`.github/workflows/ci.yml`)
- **Контроль версий**: Git + GitHub (`Ainz-Oul-Gown/roblox`)

## Быстрый старт
1. **Тестирование**:
   ```powershell
   npm test
   ```
2. **Запуск сервера синхронизации Rojo**:
   ```powershell
   npm run serve
   ```
3. **Запуск игры в Studio**:
   - Нажать кнопку **Play (F5)** в Roblox Studio.
