# Project Overview: Gen Alpha Brainrot Multiplayer Tycoon

## Описание проекта
**Gen Alpha Brainrot Multiplayer Tycoon** — полномасштабный соревновательный мультиплеерный тайкун на **8 игроков** в стилистике интернет-культуры поколения Альфа (Skibidi, Mewing, Sigma, Fanum Tax, Grimace, CaseOh, Rizzler, Tung Tung). Проект включает просторные 2-этажные базы ($48 \times 64$ studs) вокруг центральной арены ($R = 180$ studs), систему Сейфа базы со снятием наличности, Full-Loot PvP кошелька, 3 предметные способности в инвентаре для каждой фракции, линейку умножителей руды и крутую экономику с Rebirths.

## Ключевые системы и механики
1. **Просторные 2-этажные базы ($48 \times 64$ стада)**:
   - Лестница на 2-й этаж (`Stairs_To_Floor2`) с неоновыми перилами.
   - Платформа 2-го этажа (`Floor2_Foundation`), стены с защитными неоновыми рейлингами (`Floor2_Walls`).
   - Верхний конвейер (`Floor2_Conveyor`) с гравитационной наклонной шахтой сброса руды (`OreDropChute`) прямо в коллектор 1-го этажа.
2. **Сейф Сборщика (Collector Vault) и площадка вывода (WithdrawPad)**:
   - Руда от дропперов падает в Сборщик и накапливается в защищенном сейфе базы (`vaultCashMap`).
   - На вывеске над коллектором в реальном времени отображается сумма: `💸 В СЕЙФЕ: +X AURA [ВСТАНЬ, ЧТОБЫ ЗАБРАТЬ В КОШЕЛЕК]`.
   - Владелец встает на золотой пад `WithdrawPad` перед сборщиком, чтобы забрать ауру в свой кошелек.
   - Очки за удержание центральной арены ("Царь Горы") начисляются сразу в кошелек.
3. **Full-Loot PvP кошелька при гибели**:
   - При убийстве игрока другим игроком (через `creator` тег урона) 100% наличных из кошелька жертвы переходит убийце.
   - Накопленная аура в сейфе на базе **100% защищена** и остается нетронутой.
   - Экранные анимированные баннеры информируют убийцу о полученном луте (`💀 ВЫ УНИЧТОЖИЛИ... +X AURA`) и жертву о потере (`☠️ ВАС УНИЧТОЖИЛ... Потеряно -X Aura (Сейф на базе цел! 🛡️)`).
4. **Умножители руды (Upgraders)**:
   - 1-й этаж: **Лазерный умножитель** (`Upgrader_Laser`, x2, золотой лазер и неоновый металл).
   - 2-й этаж: **Квантовый умножитель** (`Upgrader_Quantum`, x3, неоновый бирюзовый луч) и **Аннигилятор Ауры** (`Upgrader_Annihilator`, x5, плазменный маджента портал).
   - Проходящие частицы руды умножаются, меняют окрас на сияющий неон и испускают снопы искр.
5. **Инвентарь способностей (3 способности на фракцию = 24 способности)**:
   - Базовая (`[1 / E]`), Тактическая (`[2 / R]`), Ультимейт 2-го этажа (`[3 / Q]`).
   - Покупаются на стойках пьедесталов и выдаются как полноценные предметы `Tool` в инвентарь (слоты хотбара 1, 2, 3).
   - Активируются экипировкой предмета и нажатием `[E]` или кликом мыши, а также горячими клавишами `[E]`, `[R]`, `[Q]`.
   - Индивидуальные кулдауны для каждого слота с живым экранным HUD.
6. **Перебалансированная экономика**:
   - Цены предметов масштабируются от $0 до $420,000+ (с учетом 2-го этажа).
   - Цены Rebirth масштабируются от $80,000 до $6,000,000 (требуют множителей для прохождения).

## Стек технологий
- **Платформа**: Roblox
- **Инструмент синхронизации**: Rojo v7.7.0 (`bin/rojo.exe`, плагин в Studio)
- **Язык**: Luau (strict typing `--!strict`)
- **Мультиплеер**: 8 независимых баз по круговой сетке ($R = 180$ studs), остров $R = 250$ studs, центральная арена `(0, 0, 0)`
- **Сохранение**: Roblox DataStoreService (`TycoonSave_v1`)
- **Тестирование**: Node.js Test Runner (`npm test`, 32 юнит-теста)
- **CI/CD**: GitHub Actions (`.github/workflows/ci.yml`)
- **Контроль версий**: Git + GitHub (`Ainz-Oul-Gown/roblox`)

## Быстрый старт
1. **Тестирование**:
   ```powershell
   npm test
   ```
2. **Запуск сервера синхронизации Rojo**:
   ```powershell
   npm run serve
   ```
3. **Запуск игры в Studio**:
   - Нажать **Stop (Shift+F5)**, затем **Play (F5)** в Roblox Studio.
