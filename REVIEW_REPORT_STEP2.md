## 3. Детальный аудит компонентов Шага 2

### 3.1. Движок бюджетирования объектов (`MAX_ACTIVE_ROCKS = 24`, `pruneOldRocks`)
```luau
local MAX_ACTIVE_ROCKS = 24
local activeRocks: { BasePart } = {}

local function pruneOldRocks(countToFree: number)
    while #activeRocks + countToFree > MAX_ACTIVE_ROCKS and #activeRocks > 0 do
        local oldRock = table.remove(activeRocks, 1)
        if oldRock and oldRock.Parent then
            oldRock:Destroy()
        end
    end
end
```
- **Анализ работы**:
  - Использована потокобезопасная FIFO-очередь (`table.remove(activeRocks, 1)`).
  - При попытке заспавнить новую партию камней (например, 8 шт.) очередь заранее освобождает ровно столько места, чтобы суммарное количество никогда не превысило жесткий лимит 24.
  - Камни уничтожаются немедленно через `:Destroy()`, снимая нагрузку с физического и рендер-движков.
- **Инженерное замечание (Minor)**:
  - Камни также регистрируются в `Debris:AddItem(rock, 1.1)`. Если новые способности не применяются долгое время, старые элементы массива могут указывать на объекты с `Parent == nil` до вызова `pruneOldRocks`. Так как массив строго ограничен константой `24`, это не приводит к утечке памяти, однако при реализации Шага 3 рекомендуется очищать массив по завершении анимации или фильтровать пустые ссылки.

### 3.2. Дистанционный отсев тяжелых эффектов (`isWithinLOD`, `LOD_DISTANCE = 120`)
```luau
local function isWithinLOD(pos: Vector3): boolean
    local camera = Workspace.CurrentCamera
    if camera then
        local dist = (camera.CFrame.Position - pos).Magnitude
        if dist > LOD_DISTANCE then
            return false
        end
    end
    return true
end
```
- **Анализ работы**:
  - Все ресурсоемкие генераторы (`spawnEarthFracture`, `spawnGroundCracks`, `spawnAnticipationVortex`, `spawnMagicCircle`, тяжелые пылевые эмиттеры в `spawnTexturedShockwave`) защищены проверкой `if not isWithinLOD(pos) then return end`.
  - При массовых PvP-баталиях на противоположном конце острова ($R = 180..250$ стадов) клиент не тратит ресурсы CPU/GPU на генерацию 3D-геометрии и эмиттеров, воспроизводя только легкие звуки и кольца. Это гарантирует стабильные 60 FPS на мобильных устройствах.

### 3.3. Процедурный разлом земли (`spawnEarthFracture`)
- **Кинематическая модель**:
  - Камни распределяются по кругу со случайным радиальным и угловым разбросом: `(i / count) * 2pi + random(-15, 15)`.
  - Материал: `Enum.Material.Slate` с палитрой базальтовых серых оттенков (`Color3.fromRGB(80, 85, 90)` и др.).
  - Размеры камней варьируются процедурно ($1.2..3.0 \times 1.8..4.2 \times 1.2..3.0$).
  - **3-фазный цикл жизни**:
    1. *Взрывной подъем*: 0.14с с наклоном по осям X/Z до $25^\circ$.
    2. *Антигравитационное зависание*: 0.22с пауза на пике высоты (эффект из лучших аниме-файтингов).
    3. *Погружение под землю*: 0.55с погружение вниз на глубину $1.2 \times sy$ с одновременным растворением `Transparency = 1`.
  - Защита `Debris:AddItem(rock, 1.1)` исключает зависание объектов в мире при любых сбоях твинов.
- **Рекомендация на Шаг 3**: Если способность применяется в прыжке или в воздухе, `pos.Y` берется из координат кастера. В Шаге 3 полезно добавить опциональный `Workspace:Raycast(pos, Vector3.new(0, -30, 0))` для привязки точки спавна камней строго к полу арены.

### 3.4. Приземные трещины (`spawnGroundCracks`)
- Создает тонкую базальтовую цилиндрическую пластину на уровне пола ($Y - 0.45$), предотвращая мерцание текстур (Z-fighting).
- Плавное затухание прозрачности за 2.5–3.5 секунды создает ощущение остаточного кратера после удара.

### 3.5. Фаза подготовки (Anticipation Vortex & Magic Circle)
- **`spawnAnticipationVortex`**: Использование отрицательной скорости эмиссии (`Speed = NumberRange.new(-25, -12)`) в комбинации с высоким сопротивлением среды (`Drag = 5.0`) создает реалистичный гравитационный вихрь, стягивающий энергию к кастеру перед ударом.
- **`spawnMagicCircle`**: Неоновый приземный круг с вращением на $180^\circ$ за 0.8с.

### 3.6. Объемные лучи (`spawnVolumetricLaser`)
- Двухслойная оптическая структура:
  1. Внешняя цветная энергетическая оболочка (толщина $1.0$).
  2. Внутренний ослепительно белый сердечник ($0.45 \times thick$, `Transparency = 0.05`).
- Автоматический импульс света `JuiceEffects.spawnLightBurst` в точке соприкосновения луча с препятствием.

### 3.7. Двухконтурная ударная волна (`spawnTexturedShockwave`)
